# #01-manuscript · *Owner: Owen (deep)*

*Purpose: Owen's editing, breakdown, and rewrite pipeline — get to a publisher-ready manuscript.*

## 📌 Canvas

> Owen has a full draft and is editing → breaking it down → rewriting. This channel tracks the
> manuscript chapter by chapter until we have (a) a clean full draft and (b) a polished sample
> we can pitch. Status convention per chapter: **Done / Editing / Rewrite / Cut**.

## Tasks

- [ ] **[Owen]** **Inventory the draft** — list every chapter and set a status (Done / Editing / Rewrite / Cut) in a chapter status sheet.
- [ ] **[Owen]** **Structural edit** — map the book's spine/outline; confirm the through-line and order; flag chapters that need a rewrite vs a light pass.
- [ ] **[Owen]** **Rewrite pass** — work chapter by chapter:
  - [ ] Rewrite the chapter
  - [ ] Line edit (clarity, tighten, voice)
  - [ ] Self-review checklist (does it open strong, earn its place, end with momentum?)
- [ ] **[Owen]** **Lock the pitch sample** — polished synopsis + the strongest 1–3 chapters, ready for publishers (feeds #02).
- [ ] **[Owen]** Pull **3–5 key ideas/quotes per chapter** as raw material for content (feeds #04).
- [ ] **[Team]** **Editor-support decision (foundation, not scheduled):** beta readers vs professional editor vs proofreader — decide what level of help the book gets.
