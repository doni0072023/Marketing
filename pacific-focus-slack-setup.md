# Pacific Focus — Slack Setup & Task Breakdown

> **What this is:** a copy-paste-ready blueprint for the Pacific Focus Slack workspace. It's
> organised the same way Slack is — one section per **channel** — with a pinned "Canvas" intro
> and owner-tagged task checklists under each. Right now the goal is **foundations**: stand up
> the content engine and have everyone step into their identity. Long-term, year-by-year timeline
> is deliberately left out.

**People & tags:** `[Owen]` author · `[Adoniah]` builder/marketer (website, GoHighLevel, content) ·
`[Bree]` launch/PR · `[Kez]` not yet onboard (warm) · `[Team]` shared decision.

---

## How to load this into Slack

1. **Create the channels** below (rename to taste — the `00–06` number prefixes keep them ordered in the sidebar).
2. For each channel, **paste the "📌 Canvas" blurb** into that channel's Canvas (top of channel → *Add a canvas*), or pin it as the first message so anyone joining sees the purpose instantly.
3. **Paste each checklist** as a message. In Slack you can either:
   - hover a line → convert to a **checklist item**, or
   - use **Slack Lists** (one List per channel) with columns *Task · Owner · Status*, and set Owner to the `[name]` tag.
4. **Invite the team:** Owen, Bree, and you. Keep **Kez's invite ready** for when she's brought on (see `#06-team-and-ops`).
5. **Handing this to Claude in Slack?** Tell it:
   > "Using this file, create these channels and populate each one with its Canvas text and its task checklist, assigning owners from the `[name]` tags."

> **Order of attack (foundations first):** `#00` set identities → `#03` + `#04` (Adoniah builds the website/funnel and content engine) running alongside `#01` (Owen's rewrite) → `#02` publishing kept warm on both tracks → `#05`/`#06` stay light until there's momentum to show.

## #01-manuscript  ·  *Owner: Owen (deep)*
*Purpose: Owen's editing, breakdown, and rewrite pipeline — get to a publisher-ready manuscript.*

**📌 Canvas**
> Owen has a full draft and is editing → breaking it down → rewriting. This channel tracks the
> manuscript chapter by chapter until we have (a) a clean full draft and (b) a polished sample
> we can pitch. Status convention per chapter: **Done / Editing / Rewrite / Cut**.

**Tasks**
- [ ] `[Owen]` **Inventory the draft** — list every chapter and set a status (Done / Editing / Rewrite / Cut) in a chapter status sheet.
- [ ] `[Owen]` **Structural edit** — map the book's spine/outline; confirm the through-line and order; flag chapters that need a rewrite vs a light pass.
- [ ] `[Owen]` **Rewrite pass** — work chapter by chapter:
  - [ ] Rewrite the chapter
  - [ ] Line edit (clarity, tighten, voice)
  - [ ] Self-review checklist (does it open strong, earn its place, end with momentum?)
- [ ] `[Owen]` **Lock the pitch sample** — polished synopsis + the strongest 1–3 chapters, ready for publishers (feeds `#02`).
- [ ] `[Owen]` Pull **3–5 key ideas/quotes per chapter** as raw material for content (feeds `#04`).
- [ ] `[Team]` **Editor-support decision (foundation, not scheduled):** beta readers vs professional editor vs proofreader — decide what level of help the book gets.
